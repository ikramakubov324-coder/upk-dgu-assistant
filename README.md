# 🎓 УПК: Цифровой помощник Колледжа ДГУ

Веб-приложение и сервисная платформа для автоматизации подачи и обработки хозяйственных/технических заявок (ИТ-оборудование, сеть Wi-Fi, электрика, мебель) в корпусах Колледжа ДГУ (г. Махачкала). 

Проект включает в себя интерактивную форму подачи заявок для студентов и преподавателей с ИИ-консультантом, панель диспетчера УПК, а также модуль генерации QR-кодов для аудиторий.

---

## 🚀 Основные возможности

* **Интерфейс заявителя (Студент / Преподаватель):**
  * Подача обращений с указанием корпуса, этажа и кабинета.
  * Выбор категории (ПК/Оборудование, Сеть Wi-Fi, Электрика, Мебель).
  * Возможность прикрепления фотографий.
* **ИИ-Консультант:**
  * Автоматический анализ текста обращения.
  * Выдача мгновенных ответов на типовые запросы (доступ к Wi-Fi, восстановление пропусков).
  * Авто-перенаправление нетиповых задач специалистам УПК.
* **Панель управления (Диспетчер УПК):**
  * Отслеживание всех входящих обращений в режиме реального времени.
  * Изменение статусов заявок (*Новая*, *В работе*, *Выполнено*, *Отклонена*).
  * Назначение ответственных специалистов и фиксация отчетов о выполнении.
* **Модуль QR-кодов:**
  * Генерация уникальных QR-кодов для аудиторий для быстрого перехода к форме подачи.

---

## 🛠 Технологический стек

* **Backend:** Python 3.10+, FastAPI, Uvicorn, PyDantic, QRCode (Pillow)
* **Frontend:** HTML5, Tailwind CSS (CDN), JavaScript (ES6+), Lucide Icons

## 📦 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
cd YOUR_REPOSITORY_NAME
```

### 2. Настройка виртуального окружения

* **Windows:**
  ```cmd
  python -m venv venv
  venv\Scripts\activate
  ```

* **Linux / macOS:**
  ```bash
  python3 -m venv venv
  source venv/bin/activate
  ```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск приложения

```bash
python hacaton.py
```

После успешного запуска приложение станет доступно по адресу: **`http://127.0.0.1:8000`**

## 🗺 Маршруты (Endpoints)

| URL | Метод | Описание |
|---|---|---|
| `/` | `GET` | Главная страница подачи заявки (Студент/Преподаватель) |
| `/admin` | `GET` | Панель управления диспетчера УПК |
| `/api/tickets` | `GET` / `POST` | Получение списка заявок / Создание нового обращения |
| `/api/tickets/{id}` | `PUT` | Обновление статуса и исполнителя заявки |
| `/api/qr?cabinet={№}` | `GET` | Генерация PNG QR-кода для указанного кабинета |
