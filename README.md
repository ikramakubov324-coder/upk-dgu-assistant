# УПК: Цифровой помощник колледжа

Веб-система для быстрой подачи обращений о проблемах в помещениях, оборудовании и инфраструктуре колледжа ДГУ (г. Махачкала). Хакатон, кейс №1.

**Команда:** while(true)
**Демо-сайт:** https://upk-dgu-assistant.onrender.com

> Сайт на бесплатном хостинге: если им давно не пользовались, первая загрузка может занять около минуты. Подождите и обновите страницу.

---

## Какую проблему решаем

Сейчас сообщить о поломке (не работает проектор, течёт кран, нет интернета) неудобно: непонятно, кому писать, заявки теряются, а на типовые вопросы сотрудникам приходится отвечать вручную.

Наше решение: человек сканирует QR-код в кабинете, описывает проблему, и система сама решает, что делать дальше.

## Как это работает

1. **QR-код.** В каждом кабинете висит QR-код. При сканировании открывается форма, где кабинет уже указан.
2. **Обращение.** Человек описывает проблему текстом и может приложить фото.
3. **ИИ-помощник** разбирает обращение и выбирает один из двух вариантов:
   - если вопрос типовой и безопасный (например, Wi-Fi или сброс пароля), сразу даёт стандартный ответ, и заявка закрывается;
   - если ответить безопасно нельзя, создаёт заявку для сотрудника.
4. **Панель сотрудников УПК.** Заявки попадают в панель диспетчера. Там можно назначить исполнителя, сменить статус (Новая, В работе, Завершена, Отклонена) и записать результат.

## Возможности

- Генерация QR-кода для любого кабинета
- Форма обращения с загрузкой фото
- Автоматический ответ на типовые вопросы
- Создание заявки, если автоответ невозможен
- Панель диспетчера: список заявок, назначение исполнителя, смена статуса, запись результата

## Технологии

- **Backend:** Python, FastAPI, Uvicorn
- **Frontend:** HTML, Tailwind CSS, JavaScript
- **QR-коды:** библиотека `qrcode`

## Структура проекта

```

├── index.html         # страница подачи обращения
├── admin.html         # панель диспетчера
└── requirements.txt   # зависимости Python
```

## API

| Метод | Адрес | Что делает |
|-------|-------|------------|
| GET | `/` | Страница подачи обращения |
| GET | `/admin` | Панель диспетчера |
| GET | `/api/qr?cabinet=304` | QR-код для кабинета (PNG) |
| POST | `/api/tickets` | Создать обращение, ИИ-помощник выбирает действие |
| GET | `/api/tickets` | Список всех заявок |
| PUT | `/api/tickets/{id}` | Изменить статус, исполнителя, результат |

## Как запустить у себя (по желанию)

Сайт уже работает по ссылке выше. Эта инструкция нужна, только если захотите запустить проект на своём компьютере.

1. Установите Python 3.10 или новее.
2. Откройте терминал в папке проекта и установите зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Запустите сервер:
   ```
   python hacaton.py
   ```
4. Откройте в браузере:
   - http://127.0.0.1:8000 — форма обращения
   - http://127.0.0.1:8000/admin — панель диспетчера
